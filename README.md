# ClockedIn for Windows

Downloads for the ClockedIn desktop app. This repository holds installers only, no source code.

**[Download the latest version](https://github.com/gurdieljepoy/clockedin-releases/releases/latest/download/ClockedIn-Setup.exe)** · [All releases](https://github.com/gurdieljepoy/clockedin-releases/releases)

## What you get

- ClockedIn in its own window, signed in with your usual account
- A small mini timer bar that stays on top of your other apps
- Closing the window keeps ClockedIn in the system tray; **Quit ClockedIn** in the tray menu shuts it down
- Optional: start with Windows

## Installing

Run `ClockedIn-Setup.exe`. The installer isn't code-signed yet, so Windows may say
"Windows protected your PC". Click **More info**, then **Run anyway**.

Quitting the app never clocks you out. Your time is tracked from clock-in to clock-out on the server.
